# UrbanCart - Medium E-Commerce Frontend

A medium-sized beginner/intermediate React e-commerce project for a Frontend Developer internship portfolio.

## Tech
- React.js
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- CSS
- Vite

## Features
- Responsive Bootstrap navbar
- Hero section
- Product cards
- Category filtering
- Product search
- Quick product view
- Add to cart
- Cart quantity controls
- Cart total
- Responsive layout
- Deal banner and feature section

## Run
npm install
npm run dev

## GitHub description
Responsive e-commerce frontend built with React.js and Bootstrap. Includes product filtering, search, quick view, shopping cart, quantity management, and responsive UI.
